Rust: Новый транспортный апдейт

5 марта 2024 | Автор: Максим Иванов | Категория: Rust

Facepunch Studios выпустили крупное обновление для Rust, которое полностью меняет систему транспорта в игре. Апдейт уже доступен на всех официальных серверах.

Новые транспортные средства

В игре появились три новых вида транспорта:

  • Модульный автомобиль - собирается из деталей, можно кастомизировать
  • Гидроцикл - быстрый водный транспорт для прибрежных зон
  • Грузовой вертолет - позволяет перевозить большие грузы между базами

Изменения в механиках

Обновление принесло значительные изменения в игровые механики:

  1. Новая система топлива - разные виды транспорта используют разные типы топлива
  2. Система повреждений - транспорт теперь можно ремонтировать
  3. Улучшенная физика столкновений
  4. Возможность устанавливать оружие на технику

Новые игровые элементы

Вместе с транспортом добавлены:

  • 15 новых чертежей для создания деталей
  • 7 видов топлива разного качества
  • Система гаражей для хранения техники
  • Новые NPC - механики, у которых можно купить редкие детали

Балансные изменения

Разработчики внесли важные балансные правки:

  • Увеличена редкость некоторых компонентов для автомобилей
  • Переработана система шума от транспорта
  • Уменьшен урон от столкновений на низких скоростях
  • Добавлена возможность угонять чужую технику при определенных условиях

Реакция сообщества

Игроки уже оценили обновление:

  • Положительные отзывы на новые возможности для рейдов
  • Критика сложности добычи топлива высокого качества
  • Похвалы за реалистичную физику транспорта
  • Пожелания добавить больше вариантов кастомизации

Разработчики обещают в ближайших патчах исправить найденные баги и добавить еще несколько видов транспорта.
